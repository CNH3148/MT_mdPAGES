## 題目

肺功能檢查顯示受試者的呼氣儲備容積(ERV) 1.3 L、吸氣容量(IC) 3.1 L、功能餘氣量(FRC)2.8L、肺活量(VC) 4.4L;肺餘容積(RV) 1.5 L,此人的總肺量(TLC)為多少L?

A.5.9
B.4.4
C.7.2
D.7.5

> [!success]- 正確解答
> **A**

---

## 筆記與詳解

### (1) 快速破題

題目要求計算**總肺量 (TLC)**，直接套用核心組合公式：


$$\text{TLC} = \text{VC (肺活量)} + \text{RV (肺餘容積)}$$


或


$$\text{TLC} = \text{IC (吸氣容量)} + \text{FRC (功能餘氣量)}$$

代入題目給定數值：

* **公式一：** $\text{VC } (4.4) + \text{RV } (1.5) = \mathbf{5.9\text{ L}}$
* **公式二：** $\text{IC } (3.1) + \text{FRC } (2.8) = \mathbf{5.9\text{ L}}$

兩者皆算出 **5.9 L**，題目給出的 ERV (1.3 L) 為重複/驗證用條件，即可秒殺選 **(A)**。

---

### (2) 專有名詞與知識點拆解

肺功能檢查中，肺容積圖表 [🖼️](https://www.google.com/search?q=%22lung+volumes+and+capacities%22+diagram&tbm=isch&udm=2) 區分為 4 個「基礎容積 (Volumes)」與 4 個「複合容量 (Capacities)」：

* **呼氣儲備容積 (Expiratory Reserve Volume, ERV)** $\rightarrow$ 平靜呼氣後，竭盡全力所能再呼出的最大氣量。
* **吸氣容量 (Inspiratory Capacity, IC)** $\rightarrow$ 平靜呼氣後，竭盡全力所能吸入的最大氣量 ($\text{IC} = \text{TV} + \text{IRV}$)。
* **功能餘氣量 (Functional Residual Capacity, FRC)** $\rightarrow$ 平靜呼氣後，肺內所殘留的氣量 ($\text{FRC} = \text{ERV} + \text{RV}$)。
* **肺活量 (Vital Capacity, VC)** $\rightarrow$ 竭盡全力吸氣後，所能呼出的最大氣量 ($\text{VC} = \text{IRV} + \text{TV} + \text{ERV} = \text{IC} + \text{ERV}$)。
* **肺餘容積 (Residual Volume, RV)** $\rightarrow$ 竭盡全力呼氣後，肺內仍殘留無法呼出的氣量（**無法由傳統肺活量計直接測得**）。
* **總肺量 (Total Lung Capacity, TLC)** $\rightarrow$ 竭盡全力吸氣後，肺內所能容納的最大總氣量 ($\text{TLC} = \text{VC} + \text{RV} = \text{IC} + \text{FRC}$)。

---

### (3) 題目選項與數據詳細解析

**數據自洽性驗證：**

* $\text{VC} = \text{IC} + \text{ERV} = 3.1 + 1.3 = 4.4\text{ L}$（吻合題目條件）
* $\text{FRC} = \text{ERV} + \text{RV} = 1.3 + 1.5 = 2.8\text{ L}$（吻合題目條件）

**選項辨析：**

* **A. 5.9**：（**正確**）$\text{TLC} = \text{VC} + \text{RV} = 4.4 + 1.5 = 5.9\text{ L}$（或 $\text{IC} + \text{FRC} = 3.1 + 2.8 = 5.9\text{ L}$）。
* **B. 4.4**：（**錯誤**）此數值僅為肺活量 (VC)，忽略了無法呼出的肺餘容積 (RV)。
* **C. 7.2**：（**錯誤**）誤將非獨立項目相加（如 $\text{VC} + \text{FRC} = 4.4 + 2.8 = 7.2\text{ L}$，此計算重複加算了一次 ERV）。
* **D. 7.5**：（**錯誤**）誤將不相關數值盲目相加（如 $\text{VC} + \text{IC} = 4.4 + 3.1 = 7.5\text{ L}$）。

---

### (4) 核心邏輯架構與記憶口訣

**縱向知識鏈結（生理位準與測量機轉）：**
平靜呼吸基線 (FRC) $\rightarrow$ 竭盡吸氣極限 (TLC) $\rightarrow$ 竭盡呼氣底限 (RV) $\rightarrow$ 可動用之最大換氣氣量為肺活量 ($\text{VC} = \text{TLC} - \text{RV}$)。

**速記口訣：**

> **「容量包含容積，總肺全包齊；餘氣 (RV / FRC) 吹不出，需要氦稀釋。」**

---

### (5) 肺容積與容量矩陣對比表

| 項目名稱 (縮寫) | 組成公式 / 定義 | 生理狀態 / 臨床特色 | 傳統肺活量計 (Spirometer) 測量 |
| --- | --- | --- | --- |
| **潮氣量 (TV)** | 獨立單項 | 平靜呼吸時，每次**吸入或呼出**氣量 | **可直接測量** |
| **吸氣儲備容積 (IRV)** | 獨立單項 | 平靜吸氣後，**再用力吸入**最大氣量 | **可直接測量** |
| **呼氣儲備容積 (ERV)** | 獨立單項 | 平靜呼氣後，**再用力呼出**最大氣量 | **可直接測量** |
| **肺餘容積 (RV)** | 獨立單項 | 竭盡呼氣後，**殘留肺內無法呼出**氣量 | **無法直接測量**（需氣體稀釋法/體流計） |
| **吸氣容量 (IC)** | **$\text{TV} + \text{IRV}$** | 平靜呼氣後，**能吸入最大氣量** | **可直接測量** |
| **功能餘氣量 (FRC)** | **$\text{ERV} + \text{RV}$** | 平靜呼氣後，**殘留肺內氣量**（胸廓與肺彈性平衡點） | **無法直接測量**（因含 **RV**） |
| **肺活量 (VC)** | **$\text{IC} + \text{ERV}$** 或 **$\text{IRV} + \text{TV} + \text{ERV}$** | 竭盡吸氣後，**能呼出最大氣量** | **可直接測量** |
| **總肺量 (TLC)** | **$\text{VC} + \text{RV}$** 或 **$\text{IC} + \text{FRC}$** | 竭盡吸氣後，**肺內容納總氣量** | **無法直接測量**（因含 **RV**） |
