## 題目

一段雙股DNA,含有20%的G,那麼C有多少比率?

A.40%
B.10%
C.20%
D.30%

> [!success]- 正確解答
> **C**

---

## 筆記與詳解

### (1) 快速破題

看到題目強調「**雙股 DNA**」並給出「**G 的比例為 20%**」時，應立刻聯想到 **查加夫法則（Chargaff's rules）** 中的「**鹼基互補配對原則**」。因為在雙股 DNA 中，鳥嘌呤（G）與胞嘧啶（C）配對，**G 的百分比恆等於 C 的百分比**（$G = C$），因此無須複雜計算即可秒答 **20%（選項 C）**。

---

### (2) 專有名詞與關鍵字拆解

* **雙股 DNA（Double-stranded DNA）** → 由兩條反向平行的多核苷酸鏈構成的雙螺旋結構 [🖼️](https://www.google.com/search?q=%22DNA+double+helix%22&tbm=isch&udm=2)。唯有在雙股結構下，兩條鏈之間的鹼基才會嚴格進行互補配對（單股 DNA/RNA 則不適用此規律）。
* **查加夫法則（Chargaff's Rules）** → 雙股 DNA 中鹼基含量的定量規律：
1. **嘌呤總量等於嘧啶總量**：$A + G = T + C = 50\%$
2. **互補鹼基等量**：$A = T$ 且 $G = C$


* **鹼基互補配對（Complementary Base Pairing）** → 鳥嘌呤（G）與胞嘧啶（C）之間以 **3 個氫鍵** 結合；腺嘌呤（A）與胸腺嘧啶（T）之間以 **2 個氫鍵** 結合。

---

### (3) 選項逐一解析

在雙股 DNA 中，四種鹼基比例總和為：


$$A + T + G + C = 100\%$$

已知 **$G = 20\%$**，推算如下：

1. 依據互補配對原則，$C = G = \mathbf{20\%}$。
2. 剩餘 $A + T$ 的比例為 $100\% - (20\% + 20\%) = 60\%$。
3. 因 $A = T$，故 $A = T = \mathbf{30\%}$。

* **A. 40%**：**錯誤**。此為 **$G + C$ 的總比例**（$20\% + 20\% = 40\%$），而非單一鹼基 C 的比例。
* **B. 10%**：**錯誤**。無相對應的計算邏輯，為干擾選項。
* **C. 20%**：**正確**。依據 $G = C$，胞嘧啶（C）的比例即為 20%。
* **D. 30%**：**錯誤**。此數值為 **A（腺嘌呤）** 或 **T（胸腺嘧啶）** 的單一鹼基比例，非 C 的比例。

---

### (4) 核心觀念縱向梳理與橫向比較

**縱向推導邏輯**
雙股 DNA 結構 → 氫鍵互補配對 ($G \equiv C$, $A = T$) → 遵守查加夫法則 ($G\% = C\%$, $A\% = T\%$) → 給定任意單一鹼基比例即可推導出其餘三種鹼基比例。

**橫向比較表：不同核酸分子之鹼基組成規律**

| 核酸分子類型 | 結構特徵 | 鹼基組成規律 | 計算特性 |
| --- | --- | --- | --- |
| **雙股 DNA** | **反向平行雙螺旋** [🖼️](https://www.google.com/search?q=%22DNA+double+helix%22&tbm=isch&udm=2) | **$G = C$**、**$A = T$**<br>**嘌呤 ($A+G$) = 嘧啶 ($T+C$) = 50%** | **知一即知全**（知道 1 種即可求出其餘 3 種） |
| **單股 DNA** | 單鏈結構 | 無互補鏈約束，**$G \neq C$**、**$A \neq T$** | 無法預測，需實際測序或實驗檢測 |
| **單股 RNA** | 單鏈結構（含 **U** 代替 T） | 無互補鏈約束，$A, U, G, C$ 比例任意 | 無法預測 |
| **雙股 RNA** | 雙鏈互補結構 | **$G = C$**、**$A = U$** | 規則同雙股 DNA，僅 **T 換成 U** |

> **解題速記口訣**：
> **「雙股互補，G 配 C、A 配 T；嘌呤嘧啶各半數，給一個算全部！」**
