## 題目

下列何種檢測檢體及保存方式的組合,可使B型肝炎病毒核酸萃取得到最佳的產量與品質?

A.全血(不含抗凝劑)/室溫
B.全血(含EDTA)/2-8°C
C.全血(不含抗凝劑)/-70°C
D.含EDTA全血之分離血漿/-70°C

> [!success]- 正確解答
> **D**

---

## 筆記與詳解

### (1) 快速破題

看到題目要求「病毒核酸 (HBV DNA)」萃取的「最佳產量與品質」，解題思路必須緊扣三個分子檢驗的核心原則：

1. **抗凝劑選擇**：必須選 EDTA，因為它能螯合 $Mg^{2+}$ 抑制核酸酶，且不會像 Heparin (肝素) 那樣抑制 PCR 反應。
2. **避免 PCR 抑制物**：全血含有大量紅血球，其中的血紅素 (Heme) 是強烈的 PCR 抑制物；白血球含有大量人類基因組 DNA，會干擾病毒萃取。因此，**絕對不能用全血直接萃取，必須分離出「血漿 (Plasma)」**。
3. **防止核酸降解**：為了長期保存確保最佳品質，必須以 **-70°C 深度冷凍** 來徹底停止核酸酶 (Nuclease) 的活性。
綜合以上，看到「核酸萃取最佳品質」，直接找「EDTA」、「血漿/血清」、「-70°C」的組合，答案即為 D。

### (2) 關鍵字與知識點拆解

* **病毒核酸萃取 (Viral Nucleic Acid Extraction)** → 目的為純化病原體 DNA/RNA。最大天敵：核酸酶 (Nuclease) 降解、PCR 抑制物 (Heme, 蛋白質)。
* **全血 (Whole blood)** → 含紅/白血球。若未分離直接冷凍，冰晶會破壞細胞膜導致嚴重溶血 (Hemolysis)[🖼️](https://www.google.com/search?q=hemolysis+blood+sample&tbm=isch&udm=2)，釋放大量血紅素與宿主 DNA，嚴重干擾檢驗。
* **EDTA (乙二胺四乙酸)** → 紫頭採血管[🖼️](https://www.google.com/search?q=EDTA+purple+top+tube&tbm=isch&udm=2)。機轉：螯合二價陽離子 ($Mg^{2+}$)。分子檢驗首選，因 $Mg^{2+}$ 是核酸酶 (DNase) 的輔因子，螯合後能抑制核酸降解。
* **血漿 (Plasma)** → 全血離心去除血球後的液體。病毒游離於其中，幾乎無細胞干擾物，為病毒載量 (Viral load) 檢測的最佳檢體。
* **-70°C 儲存** → 深低溫，完全停止任何酵素水解反應，是維持核酸完整性的最佳保存溫度。

### (3) 選項詳解

* **A. 全血(不含抗凝劑)/室溫 (錯誤)：** 不含抗凝劑會形成血塊 (凝血)。放置於「室溫」下，檢體內活躍的核酸酶會迅速將 HBV DNA 降解；且細胞代謝衰亡會釋放干擾物，品質極差。
* **B. 全血(含EDTA)/2-8°C (錯誤)：** 2-8°C 僅適用於「短期」運送 (通常短於 24~72 小時)，無法達到「最佳」品質。更致命的是保留為「全血」狀態，若未盡速分離，後續血球裂解的產物仍會干擾 PCR。
* **C. 全血(不含抗凝劑)/-70°C (錯誤)：** 這是分子檢驗的**大忌**。全血直接冷凍結冰會撐破細胞膜，解凍時發生劇烈溶血[🖼️](https://www.google.com/search?q=hemolysis+blood+sample&tbm=isch&udm=2)，釋放出巨量血紅素 (Heme，強烈抑制 Taq polymerase) 以及宿主白血球 DNA (在萃取管柱上與病毒 DNA 競爭)，導致萃取產量低且 PCR 容易**偽陰性**。
* **D. 含EDTA全血之分離血漿/-70°C (正確)：**
1. 使用 EDTA：抑制核酸酶，保護 DNA。
2. 分離血漿：去除血球，排除血紅素與宿主 DNA 的干擾。
3. -70°C 保存：凍結所有降解反應，達到最佳產量與品質。



### (4) 核心軸線與邏輯因果

**核酸檢體處理邏輯軸線：**
靜脈採血入 EDTA 管 → 螯合 $Mg^{2+}$ (核酸酶失去活性) → **離心分離血漿** (去除 RBC 避免 Heme 抑制 PCR；去除 WBC 避免宿主 DNA 競爭) → **分裝 -70°C 冷凍** (絕對靜止狀態) → 病毒核酸完整保留 → 萃取純度與產量↑ → PCR 成功擴增。

**💡 記憶口訣：分子檢驗「Ｅ 去 凍」**

* **Ｅ**：**E**DTA (紫頭管)。
* **去**：**去**血球 (務必分離血清/血漿)。
* **凍**：**凍**起來 (-70°C 深度冷凍)。

### (5) 分子檢驗 (PCR) 檢體採集與保存條件比較表

| 比較維度 | 條件選擇 | 機轉與影響 | 分子檢驗評價 |
| --- | --- | --- | --- |
| **抗凝劑** | **EDTA** | 螯合 $Mg^{2+}$ → **抑制 DNase** | **首選** |
|  | **Heparin** (肝素) | 結構類似核酸 → **強烈抑制 Taq polymerase** | **絕對禁用** (易致**偽陰性**) |
|  | **Citrate** (檸檬酸) | 螯合力弱，且為液態 → **稀釋檢體**、影響濃度 | 不建議 |
| **檢體型態** | **血漿/血清** | 去除血球細胞 → **無 Heme**、**無宿主基因組 DNA** | **最佳** (測病毒/游離核酸) |
|  | **全血** (Whole blood) | 含紅/白血球 → **Heme 抑制 PCR**、**宿主 DNA 競爭結合位** | 僅限測宿主基因/血液寄生蟲 |
| **保存溫度** | **-70°C / -80°C** | 酵素活性完全停止 → **核酸不降解** | **長期保存最佳** |
|  | **2-8°C (冷藏)** | 核酸酶活性降低，但未完全停止 | 短期運送 (< 72 h) |
|  | **未分離之全血直接冷凍** | 冰晶刺破細胞膜 → 嚴重溶血[🖼️](https://www.google.com/search?q=hemolysis+blood+sample&tbm=isch&udm=2) → **釋出 Heme 與核酸酶** | **操作大忌** (直接報廢) |
