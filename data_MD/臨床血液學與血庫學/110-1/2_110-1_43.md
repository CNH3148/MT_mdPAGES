## 題目

栓塞病人懷疑protein C缺乏時,下列何者為第一線篩檢試驗?

A.Protein C抗原(antigen)定量檢驗
B.Protein C活性(function)檢驗
C.PT
D.Reptilase time

> [!success]- 正確解答
> **B**

---

## 筆記與詳解

### (1) 快速破題

遇到篩檢體內某種「蛋白質/酵素缺乏」的題目時，一定要想到該物質的缺乏通常分為「量不夠 (Type I)」與「有量但沒功能 (Type II)」。如果第一線只測「抗原定量 (看數量)」，會漏掉「數量正常但功能異常 (Type II)」的患者。因此，**第一線篩檢永遠是先測「活性 (Function/Activity)」**，有異常再測抗原做進一步分型。

### (2) 關鍵字與知識點拆解

* **栓塞 (Thrombosis)** → 提示患者處於高凝態 (Hypercoagulability) 或有易栓症 (Thrombophilia)。
* **Protein C** → 一種維生素 K 依賴型天然抗凝劑，活化後可抑制凝血因子 Va 與 VIIIa。
* **Protein C 缺乏症分型** → Type I (抗原↓、活性↓)；Type II (抗原正常、活性↓)。
* **PT (Prothrombin Time)** → 評估外因性與共同凝血路徑，與篩檢 Protein C 無直接關聯。
* **Reptilase time (蛇毒酶時間)** → 將纖維蛋白原 (Fibrinogen) 轉化為纖維蛋白 (Fibrin) 的時間，最大特色是**不受肝素 (Heparin) 干擾**。

### (3) 詳解

* **(B) Protein C 活性 (function) 檢驗 (正確)**：為了避免漏診 Type II (功能缺陷型) 的患者，第一線篩檢必須評估 Protein C 是否能發揮正常的抗凝「功能」。若活性低下，才能確診為 Protein C 缺陷。
* **(A) Protein C 抗原 (antigen) 定量檢驗 (錯誤)**：抗原定量只能測出蛋白質的「絕對數量」。此檢驗通常作為**第二線試驗**，也就是在確認患者「活性低下」後，用來區分患者是 Type I (抗原也低) 還是 Type II (抗原正常)。
* **(C) PT (錯誤)**：PT 延長代表外因性或共同路徑 (Factor VII, X, V, II, Fibrinogen) 凝血因子缺乏或受抑制，主要用於監測 Warfarin 藥效或篩檢出血性疾病，無法用於特異性篩檢抗凝血蛋白 (Protein C) 缺乏。
* **(D) Reptilase time (錯誤)**：蛇毒酶 (Reptilase) 的作用類似 Thrombin，但它**不受 Heparin 及 Antithrombin 抑制**。主要用來鑑別診斷 Fibrinogen 異常，或在患者有使用 Heparin 時替代 Thrombin time (TT) 來評估纖維蛋白生成狀況，與 Protein C 缺乏無關。

### (4) 核心軸線與邏輯因果

* **生理機轉**：基因突變 → Protein C 蛋白質生成減少或結構異常 → 活性↓ → 無法有效分解 Factor Va、VIIIa → 凝血級聯持續活化 → **高凝態 (Hypercoagulability)**。
* **臨床表徵**：易引發深部靜脈血栓 (DVT) 導致的單側肢體腫脹發紅[🖼️](https://www.google.com/search?q=deep+vein+thrombosis+clinical+sign&tbm=isch&udm=2)、新生兒暴發性紫斑症[🖼️](https://www.google.com/search?q="purpura+fulminans"&tbm=isch&udm=2)。
* **特殊藥物關聯**：因 Protein C 半衰期短，若直接給予 Warfarin 治療，Protein C 濃度會比其他促凝血因子 (如 Factor II, IX, X) 更快下降，導致短暫的「超高凝態」，引發嚴重的微血管栓塞與 Warfarin 誘導之皮膚壞死[🖼️](https://www.google.com/search?q="warfarin+induced+skin+necrosis"&tbm=isch&udm=2)。
* **檢驗確診邏輯**：**活性篩檢 (Catch all)** → 異常 → **抗原定量 (區分 Type I/II)**。
