## 題目

乙醯氨酚(Acetaminophen)在肝臟代謝中受CYP450的作用成N-acetyl-p-benzoquinoneimine (NAPQI)的過程是屬於何種代謝反應?

A.Phase I
B.Phase II
C.Phase III
D.Phase IV

> [!success]- 正確解答
> **A**

---

## 筆記與詳解

### (1) 快速破題

看到題目關鍵字「受 **CYP450** 作用」與「生成具活性的產物 (**NAPQI**)」，應直接聯想肝臟藥物代謝的 **Phase I（第一階段）**。CYP450 (細胞色素P450) 是主導 Phase I 氧化反應的最核心酵素群；若是提及加上大分子（如葡萄糖醛酸、硫酸、穀胱甘肽）的「結合反應」，則為 Phase II。

### (2) 關鍵字與知識點解析

* **Acetaminophen (乙醯胺酚)** → 常見的解熱鎮痛劑。治療劑量下主要透過 Phase II 代謝；過量時則會大量進入 Phase I 代謝產生毒性。
* **CYP450 (Cytochrome P450)** → 肝臟微粒體酵素系統，主要負責藥物的 **Phase I** 代謝（尤其是**氧化反應**），目的是將脂溶性藥物加上極性官能基。
* **NAPQI** → Acetaminophen 經由 CYP2E1 (Phase I) 代謝產生的高度活化毒性中間產物。若無足夠的穀胱甘肽 (Glutathione, GSH) 將其中和，會導致嚴重的肝小葉中心壞死 (centrilobular necrosis)[🖼️](https://www.google.com/search?q="centrilobular+necrosis"+liver+pathology&tbm=isch&udm=2)。
* **Phase II 代謝 (Conjugation)** → 結合反應。利用轉移酶 (Transferase) 將極性大分子接在藥物或 Phase I 產物上，使其水溶性大增以利尿液或膽汁排泄。

### (3) 詳解

* **(A) Phase I 正確**：題目描述 Acetaminophen 經由 CYP450 轉化為 NAPQI。此過程為「氧化反應 (Oxidation)」，是典型的 Phase I 代謝途徑（具體酵素為 CYP2E1）。Phase I 的目的通常是將藥物「功能化 (Functionalization)」，暴露出或加上極性基團（-OH, -NH2, -SH），產物可能比原藥物更具藥理活性或毒性（如本題的 NAPQI）。
* **(B) Phase II 錯誤**：若題目問 Acetaminophen 直接代謝為無毒的 Glucuronide (葡萄糖醛酸結合物) 或 Sulfate (硫酸結合物)，或者問 NAPQI 與穀胱甘肽 (GSH) 結合解毒的過程，才屬於 Phase II 代謝 (結合反應 Conjugation)。
* **(C)、(D) 錯誤**：傳統的藥物代謝主要分為 Phase I（修飾/功能化）與 Phase II（結合/水溶化）。學理上有時會將「藥物透過穿膜運輸蛋白 (如 P-glycoprotein) 排出細胞」稱為 Phase III，但並不屬於此處的酵素代謝轉化反應；而 Phase IV 在標準藥理學代謝分類中並不存在。

### (4) 知識點梳理與因果邏輯 (縱向聯想)

**Acetaminophen 毒性機轉與臨床表現：**
Acetaminophen 過量服用 → 正常的 Phase II 代謝途徑飽和 → 藥物轉向 **Phase I (CYP2E1)** 代謝增加 → 產生大量毒性代謝物 **NAPQI** → 肝臟內的 **GSH (穀胱甘肽)** 被大量消耗殆盡 → NAPQI 與肝細胞蛋白質的巰基發生共價結合 → 導致肝細胞氧化壓力上升與粒線體失能 → **肝小葉中心壞死** → 檢驗數值：**AST/ALT 急遽↑↑** (可破千) → 臨床表徵：急性肝衰竭、黃疸 (Jaundice)[🖼️](https://www.google.com/search?q="jaundice"+clinical+sign&tbm=isch&udm=2)、凝血功能異常 (PT 延長) → 臨床解毒劑：給予 **N-acetylcysteine (NAC)** (提供 -SH 基，促進 GSH 合成以中和 NAPQI)。

**💡 記憶口訣：**

* **Phase 1** = **1** 氧化 (Oxidation) → 靠 **C**YP450 (字母第一)
* **Phase 2** = **2** 結合 (Conjugation) → 靠 **T**ransferase (轉移酶)

### (5) 藥物代謝階段橫向比較

| 比較維度 | Phase I (第一階段) | Phase II (第二階段) | Phase III (第三階段 / 擴充概念) |
| --- | --- | --- | --- |
| **核心目的** | **功能化** (加入/暴露極性基團) | **結合化** (加上極性大分子) | **排出化** (運送出細胞) |
| **主要反應類型** | **氧化 (最常見)**、還原、水解 | **葡萄糖醛酸化 (最常見)**、硫酸/穀胱甘肽結合 | 主動運輸 (ATP-dependent) |
| **核心酵素/蛋白** | **CYP450** (如 CYP3A4, CYP2E1) | **轉移酶** (如 UGTs, SULTs, GSTs) | **運輸蛋白** (如 P-glycoprotein, MRP) |
| **產物水溶性** | 稍微↑ | **大幅↑↑** | - (影響分布與排除) |
| **產物活性/毒性** | 可能消失、不變，或**增強 (如 NAPQI)** | 絕大多數**失活且無毒** (極少數例外) | - |
| **Acetaminophen 實例** | Acetaminophen → **NAPQI** | Acetaminophen → Glucuronide<br>NAPQI → NAPQI-GSH 結合物 | 代謝物經由 MRP2 進入膽汁/尿液排出 |
