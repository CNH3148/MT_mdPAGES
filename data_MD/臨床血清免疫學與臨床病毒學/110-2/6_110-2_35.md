## 題目

HLA-DO是屬於那一類型的主要組織相容性複合體(MHC)?

A.MHC I
B.MHC II
C.MHC III
D.與MHC無關

> [!success]- 正確解答
> **B**

---

## 筆記與詳解

### (1) 快速破題

看到題目問 **HLA-DO** 屬於哪一類 MHC：

* **解題邏輯**：HLA 基因命名中，只要開頭為 **HLA-D**（如 **HLA-DR、HLA-DQ、HLA-DP**，以及負責抗原處理與載入的 **HLA-DM、HLA-DO**），全部屬於 **MHC Class II** 基因區段區塊編碼的分子。
* **直接判斷**：看到 **HLA-D○** $\rightarrow$ 屬於 **MHC II (選項 B)**。

---

### (2) 專有名詞與關鍵字解析

* **HLA (Human Leukocyte Antigen，人類白血球抗原)**：人類的主要組織相容性複合體（MHC），位於第 6 號染色體短臂（6p21.3）。
* **MHC Class I (HLA Class I)**：編碼於 Class I 區段，包含經典分子（HLA-A、B、C）與非經典分子（HLA-E、F、G），負責呈遞「內生性抗原」。
* **MHC Class II (HLA Class II)**：編碼於 Class II (HLA-D) 區段，包含經典抗原呈遞分子（HLA-DR、DQ、DP）與非經典輔助分子（HLA-DM、DO），負責呈遞「外源性抗原」。
* **HLA-DO**：一種非經典 MHC Class II 異三聚體/異二聚體調節蛋白（由 $\text{DO}\alpha$ 與 $\text{DO}\beta$ 鏈組成），專一表現於 B 細胞與胸腺上皮細胞的內體/溶酶體中，主要功能為與 HLA-DM 結合並**抑制 HLA-DM 的催化活性**。

---

### (3) 題目與選項詳細解析

* **(A) MHC I**：**錯誤**。MHC Class I 區域編碼的分子名稱為「單一英文字母」，如 HLA-A、HLA-B、HLA-C（經典）以及 HLA-E、HLA-F、HLA-G（非經典）。
* **(B) MHC II**：**正確**。MHC Class II 區域（HLA-D 區）編碼所有以「D」開頭的 HLA 分子。除了呈遞抗原的 DR、DQ、DP 外，亦包含在溶酶體內協助胜肽載入與調控的 **HLA-DM** 與 **HLA-DO**。
* **(C) MHC III**：**錯誤**。MHC Class III 區域編碼的蛋白質不參與抗原呈遞，主要為**補體系統成分（C2、C4、B 因子/Factor B）**、發炎細胞因子（TNF-$\alpha$、LTA）及熱休克蛋白（HSP70）。
* **(D) 與MHC無關**：**錯誤**。HLA-DO 確實編碼於第 6 號染色體 MHC Class II 區域內，且參與 MHC Class II 抗原呈現途徑的調控。

---

### (4) 知識軸線與縱向/橫向整合

#### 縱向脈絡：MHC Class II 抗原處理與 HLA-DO 的調控機轉

1. **內質網合成**：MHC Class II（$\alpha\beta$ 鏈）在粗面內質網合成，與 **Ii 鏈 (Invariant chain)** 結合，防止內生性胜肽提前佔據結合槽。
2. **囊泡運送與降解**：MHC II-Ii 複合體進入酸性內體/溶酶體（Endosome/Lysosome），Ii 鏈被蛋白酶切割，僅殘留小片段 **CLIP** 佔據胜肽結合槽。
3. **HLA-DM 催化**：**HLA-DM** 負責踢除 CLIP，協助高親和力的外源病原體胜肽載入 MHC Class II。
4. **HLA-DO 負向調控**：**HLA-DO** 在酸性條件較弱時與 HLA-DM 結合，**抑制 HLA-DM 的活性**，防止無效或自體胜肽過度載入；直到囊泡極度酸化時作用才解除。
5. **表面呈現**：載入胜肽的 MHC II 運送至細胞膜表面，活化 **CD4+ T 細胞**。

#### 記憶口訣

* **MHC I** $\rightarrow$ **單字母**（A, B, C, E, F, G）
* **MHC II** $\rightarrow$ **D 系列**（DR, DQ, DP, DM, DO）
* **MHC III** $\rightarrow$ **補體與細胞激素**（C2, C4, BF, TNF）

#### 橫向比較：MHC Class I、II、III 核心特徵對照表

| 比較維度 | MHC Class I | MHC Class II | MHC Class III |
| --- | --- | --- | --- |
| **主要基因區域** | HLA-A, B, C (經典)<br>HLA-E, F, G (非經典) | **HLA-DR, DQ, DP** (經典)<br>**HLA-DM, DO** (非經典) | C2, C4A, C4B, CFB, TNF-$\alpha$, HSP70 |
| **結構組成** | $\alpha$ 重鏈 + **$\beta_2$-微球蛋白 ($\beta_2\text{m}$)** | $\alpha$ 鏈 + $\beta$ 鏈 (異二聚體) | 非膜表面受體蛋白（分泌性血漿蛋白/細胞激素） |
| **細胞分佈** | **所有具核細胞**及血小板 | **專職 APC**（樹突細胞、巨噬細胞、B細胞） | 血漿、細胞外液 |
