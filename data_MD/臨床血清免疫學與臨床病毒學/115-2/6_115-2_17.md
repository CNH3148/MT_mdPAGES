## 題目

病毒感染細胞後，其製造的細胞內蛋白質會經過下列何者分解成小片段胜肽，再與 MHC class I 結合並輸送至細胞表面？

A.胞內體（endosome）
B.溶酶體（lysosome）
C.蛋白酶體（proteasome）
D.胞外體（exosome）

> [!success]- 正確解答
> **C**

---

## 筆記與詳解

### (1) 快速破題

看到題目關鍵字「細胞內蛋白質（病毒蛋白）」與「MHC class I」，就要直覺聯想到**內源性抗原呈現途徑（Endogenous pathway）**。在細胞質中，負責將內源性蛋白質分解成小片段胜肽的胞器就是**蛋白酶體（proteasome）**。而如果是「外源性抗原」與「MHC class II」，對應的分解胞器才會是溶酶體/胞內體。因此直接鎖定選項 C。

### (2) 詳解預備

* **細胞內蛋白質 (Intracellular proteins) → 內源性抗原**：由細胞自身合成的蛋白質，包含正常細胞蛋白、突變腫瘤蛋白，以及受病毒感染後於細胞質內製造的病毒蛋白。
* **MHC class I → 呈現給 CD8+ T 細胞**：所有有核細胞皆具有 MHC I，專門負責展示細胞「內部」的狀況，引導胞毒性 T 細胞 (Tc) 啟動毒殺作用。
* **Proteasome (蛋白酶體) → 細胞質內的垃圾桶**：負責將被泛素（ubiquitin）標記的內源性蛋白質切割成短胜肽。
* **Endosome/Lysosome (胞內體/溶酶體) → 外源性抗原的處理廠**：細胞透過吞噬作用攝入外來病原體後，在此處以酸性水解酶分解成胜肽，供 MHC class II 呈現。

### (3) 詳解

* **正確選項 (C) 蛋白酶體（proteasome）**：病毒感染細胞後，會在細胞質內合成病毒蛋白質。這些屬於「內源性抗原」，會先被泛素化（ubiquitination），接著送到**蛋白酶體**降解為 8~10 個胺基酸長度的短胜肽，再經由 TAP (Transporter associated with antigen processing) 運送至內質網與 MHC class I 結合。
* **錯誤選項 (A) 胞內體（endosome）與 (B) 溶酶體（lysosome）**：這兩者參與的是「外源性抗原呈現途徑」。當抗原呈現細胞（APC）從細胞外吞噬細菌或外來蛋白質後，會形成吞噬體並與溶酶體/胞內體融合，利用酸性環境與水解酶將外源抗原分解，隨後與 **MHC class II** 結合。
* **錯誤選項 (D) 胞外體（exosome）**：為細胞分泌至胞外的小微小囊泡，主要功能為細胞間的訊息傳遞（攜帶 RNA、蛋白質等），與細胞內抗原的降解及 MHC 呈現途徑無直接關聯。

### (4) 核心邏輯與橫向比較

**【縱向生理邏輯】**
病毒入侵細胞 → 於細胞質合成病毒蛋白 → 泛素化標記 → **Proteasome** 分解成胜肽片段 → 經 **TAP** 蛋白送入內質網 (ER) → 與 **MHC class I** 結合 → 高基氏體修飾並送至細胞膜表面 → 活化 **CD8+ T 細胞** → 釋放穿孔素/顆粒酶破壞受感染細胞（臨床上此類病毒感染常於組織切片觀察到細胞病變 CPE[🖼️](https://www.google.com/search?q="cytopathic+effect"+viral+infection&tbm=isch&udm=2)，或於周邊血液抹片發現非典型淋巴球[🖼️](https://www.google.com/search?q="atypical+lymphocyte"+blood+smear&tbm=isch&udm=2)）。

**【記憶口訣】**

* **「內 1 蛋、外 2 溶」**：**內**源性抗原 → MHC **I** → **蛋**白酶體分解；**外**源性抗原 → MHC **II** → **溶**酶體分解。
* **「8 的法則」**：MHC **I** × CD**8** = 8；MHC **II** × CD**4** = 8。

### (5) MHC 抗原呈現途徑統整表

| 比較維度 | 內源性途徑 (Endogenous pathway) | 外源性途徑 (Exogenous pathway) |
| --- | --- | --- |
| **抗原來源** | **細胞內**合成 (病毒蛋白、腫瘤蛋白) | **細胞外**攝入 (吞噬之細菌、毒素等) |
| **表現細胞** | **所有有核細胞** | **專業抗原呈現細胞** (巨噬、樹突、B細胞) |
| **降解胞器** | **蛋白酶體 (Proteasome)** | **胞內體/溶酶體 (Endosome / Lysosome)** |
| **結合分子** | **MHC class I** | **MHC class II** |
| **活化對象** | **CD8+** 胞毒性 T 細胞 (Tc) | **CD4+** 輔助性 T 細胞 (Th) |
| **關鍵運送/輔助分子** | **TAP** (將胜肽送入內質網) | **Invariant chain (Ii)** (保護MHC II)、**CLIP**、HLA-DM |
