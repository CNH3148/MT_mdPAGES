## 題目

以X病毒感染帶有A型MHC基因的老鼠,7天後分離毒殺性T細胞,並分別與帶有A型與B型MHC基因之X病毒感染的細胞共同培養。下列何種細胞最有可能被毒殺溶解?

A.帶有A型MHC基因之X病毒感染細胞
B.帶有B型MHC基因之X病毒感染細胞
C.兩種MHC基因型之X病毒感染細胞都會被溶解
D.兩種MHC基因型之X病毒感染細胞都不會被溶解

> [!success]- 正確解答
> **A**

---

## 筆記與詳解

### (1) 快速破題

看到題目提及「**特定 MHC 基因型老鼠感染病毒** → **分離毒殺性 T 細胞 (CTL)** → **測試不同 MHC 基因型之相同病毒感染細胞**」，必須立刻聯想到免疫學的核心概念：**MHC 限制性 (MHC restriction)**（1974 年 Zinkernagel 與 Doherty 的諾貝爾獎經典實驗）。

CD8+ CTL 的辨識條件必須滿足「**雙重專一性**」：

1. **相同抗原**（X 病毒抗原肽）
2. **自體 MHC 分子**（老鼠本身的 A 型 MHC Class I）

本題老鼠為 A 型 MHC，其產生的 CTL 只能辨識並毒殺「**A 型 MHC + X 病毒抗原**」的目標細胞。選項中只有 **A** 完全符合條件。

---

### (2) 專有名詞與關鍵字解析

* **毒殺性 T 細胞 (Cytotoxic T Lymphocyte, CTL / CD8+ T cell)**：主要負責消除受病毒感染之宿主細胞或腫瘤細胞之效應細胞。
* **第一型主要組織相容性複合物 (MHC Class I)**：表達於所有**有核細胞**表面，負責處理並呈遞**內源性抗原**（如病毒蛋白、腫瘤抗原）給 CD8+ T 細胞。
* **MHC 限制性 (MHC Restriction)**：T 細胞受體 (TCR) 在辨識抗原時，必須同時認得「專一性抗原肽段」與「自體 MHC 分子」，否則無法活化或執行毒殺。

---

### (3) 題目與選項詳細剖析

#### 核心反應機轉

1. **致敏階段 (Sensitization)**：A 型基因型老鼠感染 X 病毒，體內 A 型 MHC Class I 將 X 病毒蛋白肽段呈遞於細胞表面。CD8+ T 細胞經 TCR 辨識「MHC-A + X 病毒肽」後被活化增殖為效應 CTL。
2. **毒殺階段 (Cytotoxicity)**：
* **對抗 A 型 MHC + X 病毒細胞**：TCR 正確辨識自體 MHC-A 及 X 病毒抗原，觸發免疫神經鏈結 (Immune synapse)，釋放穿孔素 (Perforin) 與顆粒酵素 (Granzyme)，誘導目標細胞凋亡與溶解 [🖼️](https://www.google.com/search?q=Cytotoxic+T+cell+target+cell+lysis&tbm=isch&udm=2)。
* **對抗 B 型 MHC + X 病毒細胞**：雖然帶有相同的 X 病毒抗原，但因 MHC 基因型不符（非自體 MHC-A），TCR 無法正確結合，不發生毒殺作用。



#### 選項剖析

* **A. 帶有A型MHC基因之X病毒感染細胞**（**正確**）：完全滿足自體 MHC 限制性（MHC-A）與專一抗原（X 病毒），觸發 CTL 毒殺溶解反應。
* **B. 帶有B型MHC基因之X病毒感染細胞**（**錯誤**）：不符合自體 MHC 限制性（異體 MHC-B），CTL 無法辨識，不被溶解。
* **C. 兩種MHC基因型之X病毒感染細胞都會被溶解**（**錯誤**）：忽略了 T 細胞具備 MHC 限制性之原理。
* **D. 兩種MHC基因型之X病毒感染細胞都不會被溶解**（**錯誤**）：A 型 MHC 感染細胞符合辨識條件，會被正常溶解。

---

### (4) 核心機轉與橫向整合

#### 縱向生理與檢驗邏輯軸線

> **宿主感染病毒 X** → **Proteasome 降解內源性病毒蛋白** → **TAP 輸送至內質網** → **MHC Class I (A型) 呈遞抗原肽於細胞膜** → **CD8+ T 細胞 TCR 雙重辨識 (MHC-A + X 肽)** → **選殖擴增為成熟 CTL** → **體外共培養遇目標細胞 (MHC-A + X 肽)** → **釋放 Perforin / Granzyme** → **目標細胞膜穿孔與細胞溶解 (Lysis)**

#### 橫向比較：T 細胞子群與 MHC 限制性對比

| 比較維度 | CD8+ 毒殺性 T 細胞 (CTL) | CD4+ 輔助性 T 細胞 (Th) |
| --- | --- | --- |
| **MHC 限制類型** | **MHC Class I** | **MHC Class II** |
| **共受體 (Co-receptor)** | **CD8**（結合 MHC-I $\alpha_3$ 區域） | **CD4**（結合 MHC-II $\beta_2$ 區域） |
| **抗原來源** | **內源性抗原** (病毒、胞內菌、腫瘤) | **外源性抗原** (胞外菌、寄生蟲、蛋白質抗原) |
| **抗原呈遞細胞 (APC)** | **所有有核細胞** | **專業 APC** (樹突細胞、巨噬細胞、B 細胞) |
| **主要效應機制** | **Perforin / Granzyme 毒殺、FasL 誘導凋亡** | **分泌細胞激素** (IFN-$\gamma$, IL-4, IL-17 等) |
| **本實驗之表現** | **僅毒殺「自體 MHC + 對應抗原」** | 需「自體 MHC-II + 對應抗原」方能活化 |

> **快速記憶口訣**：
> 「**八一內毒，四二外輔；雙重辨識，非親不殺**」
> * **八一內毒**：CD**8** 結合 MHC Class **I**，針對**內**源抗原，執行**毒**殺作用。
> * **四二外輔**：CD**4** 結合 MHC Class **II**，針對**外**源抗原，執行**輔**助作用。
> * **非親不殺**：異體/非自體 MHC 分子，TCR 無法辨識，不觸發細胞毒殺（MHC 限制性）。
